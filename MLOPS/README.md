# MLFLOW
- MLFlow: build better models and generative AI apps on a unified, end-to-end, open source MLOps platforem
- Integrates with any ML library & platform

- Data scientist levarage MLFlow for:
    1. Experiment tracking & hypothesis testing
    2. Code structuring
    3. Model Packaging & dependency management
    4. Evaluating hyperparameter tuning
    5. Compare the results of models retraining over time

- MLOPS proffesional leverage MLFlow for:
    1. Manage the lifecycle of trained models both pre & post deployment
    2. Deploy models scurly to the production enviornment
    3. Manage deployment dependecies

- Prompt Engineering Users:
    1. Evaluate and experiment with large language models
    2. Create custom prompts and experiment
    3. Deciding on the best model suitable for project requirments

- Usecases:
    1. Experiment tracking --> Track parameters and metrics with *UI*
    2. Model selection and Deployment
    3. Model performance monitoring
    4. Collaborative project

- Model Registry: a centralized repository and lifecycle management tool for machine learning models. It provides version control, stage transitions, model aliases, lineage tracking, and metadata annotations to move models safely from experimentation to production
